# Prof. D. J. Manowar — Academic Portfolio

A responsive, static personal academic website built with HTML, CSS and vanilla JavaScript. It is designed for free hosting on GitHub Pages.

## Preview locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Sign in to GitHub and create a new **public** repository named exactly `YOUR-USERNAME.github.io`.
2. Upload the contents of this folder (the `index.html`, `styles.css`, `script.js`, and `assets` folder) to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. Wait for the deployment to complete. Your site will appear at `https://YOUR-USERNAME.github.io/`.

## Before publishing: content checklist
- Replace the portrait placeholder with a professional photograph.
- Add a verified professional email address and preferred contact details.
- Add exact titles, authors, journals/conferences, years, DOI links and publisher details for publications.
- Add patent title, application/grant number and grant date.
- Add book and book-chapter bibliographic details.
- Add links to NPTEL certificates and other credentials.
- Confirm the wording of current designation and institutional affiliation.
- Add event photographs only where you have permission to publish them.

The site intentionally avoids inventing publication titles, patent numbers, email addresses or other bibliographic details.
